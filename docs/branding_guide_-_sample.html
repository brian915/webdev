Icons should clarify meaning at a glance. Use them to reinforce labels and navigation, not as decoration.

Sizing

Simple scale

Keep sizes predictable. Icons should match the text they sit beside.

Body
16px
Buttons
20px
Nav / Feature
24px

Choose a single icon weight and keep it consistent across UI. If you later adopt multiple weights, reserve the heavier weight for emphasis, not routine navigation.

Color

Inherit by default

Icons should usually inherit the text color of their container. Use accent colors only for interactive states or to signal a system status.

Default inherits
Accent interactive
Alert status

On dark surfaces, rely on the existing text color tokens (for example, text-on-dark) and let icons inherit.

Component examples

Rule of thumb: if the icon can’t be correctly named out loud, it’s not doing useful work.

Accessibility

Always label icon-only controls

If there is no visible text label, add an accessible label with aria-label. If the icon is purely decorative, hide it from assistive tech with aria-hidden="true".
